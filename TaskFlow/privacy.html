Privacy Policy

Effective Date: October 10, 2026 | Version 1.0

1. Overview and Core Privacy Principle

TaskFlow is designed from the ground up as an offline-first, client-side productivity application. We believe that your personal tasks, schedules, and work habits are strictly confidential and belong solely to you.

Because TaskFlow runs entirely within your web browser, no personal data, task contents, or usage analytics are ever collected, transmitted, stored, or processed on any remote server.

2. Data Storage and Local Isolation

All data created within TaskFlow is stored exclusively in your browser's sandboxed localStorage API. This includes:

  • Task titles, descriptions, due dates, priority labels, and tags
  • Custom and default category configurations
  • Focus timer session counts and historical completion timestamps
  • Interface preferences, including light/dark theme selection and sound toggles

This data remains strictly on your local device. It is not synchronized across devices automatically and cannot be accessed by external websites or unauthorized parties.

3. Third-Party Services and Analytics

TaskFlow does not integrate with any third-party advertising networks, analytics trackers, cloud databases, or external telemetry providers. We do not use tracking pixels, external fonts, or remote trackers.

4. Data Portability and User Control

You have complete control over your data at all times:

  • Exporting: You can export a full JSON backup of all stored tasks and preferences at any time via the Settings panel.
  • Importing: You can restore backups using the Import tool, which validates JSON schemas locally before saving.
  • Deletion: You can permanently wipe all stored data using the "Reset Application" button in Settings, or by clearing your browser's site data and cookies.

5. Changes to This Privacy Policy

Any updates to this policy will be documented in the open-source repository and reflected on this page. Because we collect no contact information, we encourage users to review this page periodically.
